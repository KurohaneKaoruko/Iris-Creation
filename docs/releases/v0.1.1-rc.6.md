# Iris-Creation v0.1.1-rc.6 · 内测候选版

第六个安装验收候选版，包含剧本分镜与本地参考素材流程：为稳定场次路径编排镜头、调整顺序、景别、运镜和规划时长；导入 PNG/JPEG/WebP 图片并保留原图、校验值与本地缩略图。镜头、素材及相对路径随整个作品目录复制。分镜保存会检测磁盘版本冲突，普通文件操作不能绕过分镜保护。此候选版不包含付费图像或视频生成。

浏览器界面不把原始参考图发送给模型服务。完整备份仍须复制整个作品目录（包括 `creative/` 与 `.novel/`）；应用内校验清单不是正文副本，也不校验二进制原图。

本候选版通过前端、Rust、RPC/模拟 Provider、浏览器与跨目录复制验收。Windows、macOS、Linux 安装、升级与稿件恢复仍须在对应平台人工验收；见 `docs/acceptance-v0.1.1-rc.5.md`。
