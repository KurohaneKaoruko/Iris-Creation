# Iris-Creation v0.1.1-rc.4 · 内测候选版

这是安装验收候选版，不是稳定版。rc.1/rc.2/rc.3 均未产生公开安装包：前两次发布矩阵的附加测试失败，rc.3 则在 Linux Tauri RPM 打包失败。

rc.3 的 Linux 失败已本机复现：Debian 包成功；RPM 因 RPM `Version` 字段不接受 SemVer `-rc.N` 里的连字符而失败。本版先用完整候选版本构建应用和 DEB/AppImage，RPM 元数据单独映射为 `Version=0.1.1, Release=0.rc.4`，使候选低于最终 `0.1.1-1`。Windows/macOS 安装器保留完整候选版本。

本机已验证 rc.3/rc.4 对应的 DEB/RPM 可生成，并用 `rpm -qp` 检查到候选 Release 字段。rc.4 的 Linux 构建步骤尚需远端复验；Windows/macOS bundle 也在本轮失败，本机无权限读取详细 Actions 日志。

请先使用作品副本内测。安全、备份限制和人工验收清单见 `docs/acceptance-v0.1.1-rc.4.md`。
