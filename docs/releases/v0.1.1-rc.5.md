# Iris-Creation v0.1.1-rc.5 · 内测候选版

这是第五个安装验收候选版，不是稳定版。rc.1/rc.2 因发布矩阵测试未完成而停止；rc.3 因 RPM 不接受 SemVer prerelease 的连字符而停止；rc.4 的 Windows/macOS bundle 步骤失败（详细 runner 日志不可读取）。rc.4 曾给 pnpm bundle 脚本额外传递 `-- --ci`，本版恢复上一轮通过的 `pnpm run tauri:build` 调用。

Linux 预发布 RPM 版本字段修正保留：原始 rc 版本用于构建应用、DEB/AppImage；独立 RPM 元数据使用基础版本及 `0.rc.5` release，使候选版本低于正式 release `1`。所有平台仍需本标签的 GitHub Actions 实跑通过后才会生成公开预发布。

详细功能限制、备份提示和人工验收清单见 `docs/acceptance-v0.1.1-rc.5.md`。
