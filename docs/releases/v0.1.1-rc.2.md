# Iris-Creation v0.1.1-rc.2 · 内测候选版

这是第二个安装验收候选版，不是稳定版。`v0.1.1-rc.1` 的发布任务在 Linux、macOS、Windows 的 Rust 测试步骤均以 exit 101 失败，未生成安装包；主 CI 的完整 Rust 套件通过，但无仓库管理员权限，无法读取失败 runner 的详细日志。本版在发布矩阵运行便携库/桌面启动回归测试，完整 Rust 套件仍由主 CI 负责。

## 内容

- 包含 `v0.1.1-rc.1` 的启动、写作安全、快速打开、检索、模型设置和备份提示改进。
- 发布前严格检查统一版本、五个目标安装包、SHA256SUMS、上传大小和服务端 SHA-256 digest。
- 既有 Release 或草稿不自动删除、不覆盖；上传或校验失败时保留远端草稿供人工检查。
- 备份页明确为文件校验清单，不包含可恢复正文；完整备份必须复制整个作品目录。

## 验收边界

- Linux 本地真实服务、RPC/WS、保存冲突、历史恢复、导出、停止生成、异常响应、重启和外部目录副本验收已通过。
- 主 CI 已通过前端 295 项测试、完整 Rust 测试、发布安全测试和本地模拟 Provider 验收。
- GitHub 三平台构建还需要以本标签的 Actions 结果为准；构建成功不等于 Windows/macOS 真机安装、升级或签名公证完成。
- AI 候选验收使用本机模拟 Provider；真实 Provider、断网重连、长篇连续写作、磁盘写满/断电和完整备份恢复仍需人工验证。

详细清单见 `docs/acceptance-v0.1.1-rc.2.md`。
