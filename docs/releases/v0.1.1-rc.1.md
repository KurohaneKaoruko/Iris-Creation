# Iris-Creation v0.1.1-rc.1 · 内测候选版

这是用于安装与写作流程验收的预发布版，不是稳定版。请先使用作品副本测试，不要将唯一一份重要稿件交给候选版。

## 相较 v0.1.0

- 修复桌面发布态前端资源加载和数据目录定位；本地端口占用时寻找可用端口，启动失败给出明确提示。
- 增加未保存修改保护、本地恢复草稿、磁盘修改冲突确认，以及专注写作模式。
- 完善章节标题/文件名/路径快速打开、最近文档、全文检索取消和精确源行定位。
- 模型配置保存失败保留表单；激活模型仅在后端写入成功后更新，防止界面与磁盘状态不一致。
- 明确“备份”页生成的是文件校验清单，不包含可恢复的正文副本。
- 发布流程先运行测试，再构建三个平台安装包；只接受五种完整安装包及 SHA256SUMS，核对上传大小和 SHA-256 后才公开。既有 Release 不自动删除或覆盖。

## 安装包范围

- Windows x64：NSIS 安装程序（`*-setup.exe`），不再把依赖资源目录的裸桌面 EXE 当作安装包发布。
- macOS Apple Silicon：DMG；不包含 Intel Mac 安装包。
- Linux x64：AppImage、DEB、RPM。

## 验收边界与数据安全

- 本地验收包含真实 RPC/WS 服务、保存重开、历史恢复、导出、强制终止进程后重启，以及外部目录副本打开。
- AI 异常验收使用本机模拟 Provider，不接触真实密钥、不消费付费模型额度。真实模型兼容性、输出质量与公网断网重连仍需实际验证。
- GitHub 三平台构建与自动测试不能替代 Windows/macOS 真机安装、首次启动、系统权限提示和旧版升级测试。
- 不保证代码签名或 Apple 公证；系统可能显示未验证发布者提示。
- 当前“文件校验清单”只能核对文件状态，不能恢复丢失正文。完整备份请先保存并退出，再复制整个作品目录（包括 `.novel/`）到其他存储位置；应实际打开副本检查。
- Windows API Key 使用 DPAPI；当前 macOS/Linux 的本地 secrets 文件仅做 Base64 编码，并不等于加密。请妥善保护应用数据目录，不要上传到公开仓库。
- 连续长篇写作、磁盘写满/断电、跨版本迁移和自动备份恢复尚未完成全面验收。

详细步骤见仓库 `docs/acceptance-v0.1.1-rc.1.md`。
