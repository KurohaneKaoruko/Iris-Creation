# Iris-Creation v0.1.1-rc.3 · 内测候选版

这是第三个安装验收候选版，不是稳定版。rc.1/rc.2 在发布矩阵失败，未生成公开安装包。主 CI 的 Rust 测试通过；矩阵日志受权限限制。rc.3 的 Windows/macOS 构建和模拟服务验收已通过，Linux Tauri 打包发现上游 RPM 工具不接受 SemVer `-rc.N` 字符。已验证的修正是：先以原始 rc 版本构建 DEB/AppImage，再单独打 RPM，把 RPM 的版本元数据映射为 `Version=0.1.1, Release=0.rc.N`，从而仍低于正式版 `0.1.1-1`；应用二进制仍由原始候选版本构建。

本版由主 CI 负责一次完整 Rust 测试；平台矩阵必须逐平台构建 Tauri 安装包与服务程序，并通过本机模拟 Provider 的 RPC/WS 写作、安全和重启检查。任何步骤失败都不发布。旧候选标签不移动、不覆盖。

其余功能、安装器平台范围、数据与密钥限制详见 `v0.1.1-rc.2.md` 与 `docs/acceptance-v0.1.1-rc.3.md`。
