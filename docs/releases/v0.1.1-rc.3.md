# Iris-Creation v0.1.1-rc.3 · 内测候选版

这是第三个安装验收候选版，不是稳定版。rc.1 和 rc.2 都没有公开安装包；两个尝试均在发布矩阵的额外 Rust 测试步骤停止。主 CI 的完整 Rust 测试通过，但公开 Actions API 没有提供失败 runner 原始日志（需要仓库管理员权限），无法可靠断定该重复矩阵步骤失败的具体原因。

本版由主 CI 负责一次完整 Rust 测试；平台矩阵必须逐平台构建 Tauri 安装包与服务程序，并通过本机模拟 Provider 的 RPC/WS 写作、安全和重启检查。任何步骤失败都不发布。旧候选标签不移动、不覆盖。

其余功能、安装器平台范围、数据与密钥限制详见 `v0.1.1-rc.2.md` 与 `docs/acceptance-v0.1.1-rc.3.md`。
