# v0.1.1-rc.1 可用性验收

## 结论

目标是内测候选版，不是稳定版承诺。自动验证通过只说明下列受控场景有效，不意味着所有平台已完成真机验收。

## 可重复的本地验证

```bash
pnpm run lint
pnpm run test
pnpm run build
node scripts/version.mjs check v0.1.1-rc.1
node --test scripts/release.test.mjs
cargo test --locked --manifest-path src-tauri/Cargo.toml
cargo build --locked --manifest-path src-tauri/Cargo.toml --bin iris-creation-server
node scripts/smoke-test.mjs
```

`smoke-test.mjs` 启动实际服务进程，工作目录不在仓库；数据保存在独立临时目录，端口由 OS 分配。测试只连接本机模拟 Provider，不读取用户配置或真实 Key，结束后清理自己创建的目录。

### 自动验收场景

| 范围 | 断言 | 不代表什么 |
| --- | --- | --- |
| 生产前端与启动 | 首页、入口 JS、health、RPC 可访问；缺失静态资源返回 404 | 不替代安装器或桌面 WebView 启动 |
| 保存与冲突 | 中文、emoji、CRLF 保存读回一致；旧基线不能覆盖新文件 | 不模拟断电或磁盘硬件故障 |
| 历史与导出 | 自动历史可读、恢复结果一致、合并导出包含章节内容 | 不等同于独立整工程备份 |
| 路径边界 | 拒绝 `../` 形式越界读取 | 不是完整安全审计 |
| AI 正常链路 | 本机 SSE token 经 WS 正确返回，可停止在途生成 | 不验证真实模型质量与协议差异 |
| AI 失败链路 | 缺密钥、401、损坏 JSON、连接断开均返回错误；原稿保持不变 | 不验证公网重试或长时间超时 |
| 重启持久化 | 强制终止服务后，设置、已保存会话和章节仍可读 | 不保证未保存内存数据永不丢失 |
| 外部副本恢复 | 服务停止后复制整个作品目录，重启后副本正文与历史可读 | 软件目前没有一键完整备份/恢复功能 |
| 发布防护 | HTTP/JSON 错误立即失败；既有草稿/公开 Release 都不删除；包数量、大小、哈希异常禁止公开 | 单元测试不是线上发布成功记录 |

## GitHub 发布门禁

1. 前端类型检查、单元测试、生产构建和版本一致性检查。
2. 三个平台各自运行 Rust 测试与实际服务进程验收，再汇总完整安装包。
3. POSIX shell 外部 CLI fixture 只在 Linux/macOS 运行；Windows 不将它计为已通过。
4. 安装包只能有 NSIS、DMG、AppImage、DEB、RPM 各一个，另附 SHA256SUMS；不发布裸 EXE。
5. 先创建草稿，逐个上传，验证服务端记录的大小和 SHA-256，然后公开预发布。候选版不标记为 Latest。
6. 失败不删除已有 Release，也不自动清理失败草稿；维护者必须检查原因和远端状态再决定如何处理。

## 必须补做的人工验收

- [ ] Windows x64：在非开发机安装、首次启动、退出重开；占用首选端口时能正常启动。
- [ ] Windows：已有版本升级后，作品路径、设置、密钥和历史不丢失。
- [ ] macOS Apple Silicon：DMG 安装、权限/签名提示、首次启动、退出重开、升级。
- [ ] Linux：本候选版实际安装包在干净环境安装与桌面启动（之前版本的打包测试不自动算作本版通过）。
- [ ] 真实模型：配置、连通性测试、生成、停止、保存、重开和服务端限流/断网提示。
- [ ] 长篇工程：连续写作与跨章节操作；异常退出后草稿恢复；完整目录离线备份恢复演练。
- [ ] 磁盘空间不足/写入权限拒绝时，原稿不损坏、错误可见、用户可重试。

这些项目未完成前，不应称为“可以放心承载唯一原稿的稳定版”。
